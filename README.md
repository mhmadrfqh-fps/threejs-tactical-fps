# Tactical FPS - Three.js Bounty Entry

Live Demo: https://mhmadrfqh-fps.github.io/threejs-tactical-fps/
Bounty: make.fun/bounty/threejs-fps-02
Author: @muhammad-rofiq / mhmadrfqh-fps

## Features
- First Person Tactical Shooter
- WASD Movement + Mouse Look (Pointer Lock)
- Raycast Shooting System
- Enemy Capsule AI (3 enemies)
- Minimap Tactical View (canvas)
- Fog, GridHelper, Cover Walls

## Tech
Three.js 0.160.0 via importmap, vanilla JS, no build step.

## How to Play
Click to lock, WASD move, mouse aim, click shoot. Kill all enemies to respawn.
